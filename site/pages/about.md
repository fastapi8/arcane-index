Arcane Index is a data-backed reference for Arcane Odyssey's cooking system. It
exists because the game's cooking mechanics are nowhere documented in full, and
the pieces that are documented tend to disagree with each other.

## How is this different from the wiki?

Most existing references describe cooking mechanics as generalized observations.
This project aims to derive fundamental cooking mechanics through reverse
engineering techniques and careful documentation.

## Status

This is an active research project. We are always looking for more helpers. If
anyone is interested in participating, please reach out either in game or on
reddit. We might create a dedicated discord server in the future.
